# P0 作業 · 系統填寫器（分批 Markdown）

本資料夾是 [kiao-ai-course](../) 課程庫中的 **P0 作業**。

對齊 [HSAILEARNING P0 系統](https://roy722-creator.github.io/HSAILEARNING/) 的題目分類與結構，加上**批次匯出／匯入 Markdown**，方便題目太多時分次填寫。

## 怎麼用

1. 用瀏覽器開啟 `index.html`
2. 依需求填寫各層（小孩／青少年／成人、狀態層、職涯／親職／重大決定、伴侶）
3. 內容會自動存在瀏覽器 localStorage

### 分批離線填寫

1. 點工具列「匯出全部空白模板」→ 下載 8 個空白 `.md`
2. 用任何編輯器填答案（保留 `<!-- key:... -->` 不要刪）
3. 回到本頁「匯入 Markdown」，可一次選多檔合回來
4. 匯入模式可選「只填空白」或「覆寫已有」

### 其他

- **批次匯出已填內容**：只匯出有進度的模組
- **匯出／匯入 JSON 備份**：完整草稿備份與還原
- 各區塊也可單獨「匯出」或「匯出空白模板」

## 注意

- 資料只存在本機瀏覽器與你匯出的檔案，不會上傳
- 題目結構來源為原站 P0 系統 v1.0；本頁為填寫輔助工具
